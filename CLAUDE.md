## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues (backpaper0/passui) via the `gh` CLI. See `docs/agents/issue-tracker.md`.

To split a plan or a grilling result into tickets, ask the user to run `/to-tickets` instead of filing the tickets yourself.

### Triage labels

Uses the default five triage labels (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
